# 显卡选型规则（7B / 13B / 70B 模型）

> 本文档面向初学者，详细说明如何在 AutoDL 上为大模型微调与部署选择合适的显卡。
> 重点讲解 **7B 和 13B** 模型，70B 仅作简要说明（本项目不涉及）。

## 📌 一句话规则：4-8 倍显存

> **核心规则**：显卡显存应至少为模型参数量对应显存的 **4-8 倍**。

| 模型参数量 | 模型原始大小(FP16) | 推理显存 | 训练显存（全量） | 训练显存（LoRA） |
|-----------|-------------------|----------|----------------|-----------------|
| **7B**    | 14 GB             | 16 GB    | 80 GB          | **24 GB** ✓     |
| **13B**   | 26 GB             | 28 GB    | 160 GB         | **40 GB** ✓     |
| 70B       | 140 GB            | 150 GB   | 600 GB         | 80 GB           |

**为什么训练显存是推理的 4-8 倍？**
1. 模型权重本身（1 倍）
2. 梯度（1 倍）
3. 优化器状态 AdamW（2 倍）
4. 激活值（取决于 batch size 和 seq_len，通常 1-4 倍）
5. 总计：约 5-8 倍

**LoRA 训练为什么省显存？**
- LoRA 只训练低秩矩阵，**冻结原模型权重**
- 不需要保存原模型的梯度和优化器状态
- 只需要保存激活值和 LoRA 适配器（约 1% 参数）
- 因此训练显存大幅降低

## 🎯 7B 模型选型详解（本项目推荐）

### 推荐配置：1 张 RTX 4090 (24GB)

| 项目阶段 | 显存需求 | 推荐显卡 | 显卡显存 | 是否满足 |
|---------|---------|---------|---------|---------|
| 数据预处理 | 0 GB | CPU 即可 | - | ✓ |
| LoRA 训练 | 20-22 GB | RTX 4090 | 24 GB | ✓ |
| 模型合并 | 16 GB | RTX 4090 | 24 GB | ✓ |
| GPTQ 量化 | 18-20 GB | RTX 4090 | 24 GB | ✓ |
| vLLM 部署 | 6 GB | RTX 4090 | 24 GB | ✓（甚至可以更小） |

### 显存占用估算公式（7B 模型，LoRA 训练）

```
总显存 = 基础开销 + 训练开销

基础开销:
  - 模型权重 (FP16):    7B × 2 字节 = 14 GB
  - 梯度 (LoRA 部分):   0.1 GB
  - 优化器 (LoRA):      0.2 GB

训练开销:
  - 激活值 (bs=4, seq=2048):  约 6 GB
  - DeepSpeed ZeRO-2 优化:    减少 30-50%

合计: 约 14 + 0.3 + 6 × 0.6 ≈ 18 GB
保留 20% 余量: 推荐 ≥ 22 GB
```

## 🎯 13B 模型选型详解

### 推荐配置：1 张 A100 (40GB) 或 2 张 RTX 4090

| 项目阶段 | 显存需求 | 单卡方案 | 双卡方案 |
|---------|---------|---------|---------|
| LoRA 训练 | 35-40 GB | A100 (40GB) | 2×RTX 4090 (各 24GB) |
| 模型合并 | 28 GB | A100 (40GB) | 单卡 RTX 4090 即可 |
| GPTQ 量化 | 30-35 GB | A100 (40GB) | 单卡 RTX 4090（紧） |
| vLLM 部署 | 10 GB | RTX 4090 (24GB) | 单卡 RTX 4090 |

### 13B 的关键选择：单卡 A100 vs 双卡 4090

| 方案 | 显卡 | 时租 | 优点 | 缺点 |
|------|------|------|------|------|
| **单卡 A100** | A100 40GB | ¥5.5/h | 配置简单、无通信开销 | 贵 |
| **双卡 4090** | 2×RTX 4090 | ¥5.0/h | 便宜 | 需配置 tensor-parallel |

**建议**：
- 初学者：选 **单卡 A100 (40GB)**，配置最简单
- 进阶用户：选 **2×RTX 4090**，成本更低，但需配置 DeepSpeed 多卡训练

### 双卡 4090 训练配置要点

```bash
# 必须使用 LLaMA-Factory + DeepSpeed ZeRO-2 多卡训练
# 修改 configs/qwen25_lora.yaml 中的配置后:
llamafactory-cli train configs/qwen25_lora.yaml
# 或用 deeppeed 启动器启动 LLaMA-Factory
deepspeed --num_gpus 2 -m llamafactory.train configs/qwen25_lora.yaml
```

注意 13B 模型加上 DeepSpeed 通信开销，**实际可用显存会减少 10-15%**，所以单卡 4090 训练 13B 风险较大，推荐双卡。

## 📐 显存计算速查公式

### 推理显存
```
推理显存 ≈ 模型参数量 × 2 字节 + 1 GB（KV Cache）
量化后推理显存 ≈ 模型参数量 × 0.5 字节 + 1 GB（KV Cache）
```

### LoRA 训练显存
```
LoRA 训练显存 ≈ 模型参数量 × 2 字节 × 1.3 + batch_size × seq_len × 4KB × 层数
```

### 全量微调显存
```
全量微调显存 ≈ 模型参数量 × 2 字节 × 5  (AdamW 优化器)
```

### 估算示例（7B 模型，FP16，LoRA 训练，bs=4，seq=2048）
```
基础开销 = 7 × 2 × 1.3 = 18.2 GB
激活值开销 = 4 × 2048 × 4KB × 32 = 1 GB
合计 ≈ 19 GB
推荐显存 = 19 × 1.2 = 23 GB  → 选 RTX 4090 (24GB)
```

## 💰 AutoDL 成本估算（7B 模型全流程）

| 步骤 | 时长 | 显卡 | 费用 |
|------|------|------|------|
| 数据预处理 | 10 分钟 | 不用 GPU | ¥0 |
| 下载模型 | 30 分钟 | 不用 GPU | ¥0 |
| LoRA 训练（小数据集） | 2-4 小时 | RTX 4090 | ¥5-10 |
| 模型合并 | 10 分钟 | RTX 4090 | ¥0.5 |
| GPTQ 量化 | 1-2 小时 | RTX 4090 | ¥2.5-5 |
| vLLM 部署测试 | 30 分钟 | RTX 4090 | ¥1.2 |
| **总计** | **4-7 小时** | | **¥9-17** |

**省钱技巧**：
1. 数据预处理和模型下载用 CPU 实例（更便宜）
2. 训练时小数据集可以降低 epoch 数
3. 量化时减少校准样本数（128 → 64）
4. 不需要 GPU 时及时关机

## 📝 实操建议

### 1. AutoDL 租用流程
1. 注册 [AutoDL](https://www.autodl.com/) 账号
2. 充值（推荐先充 ¥20 试水）
3. 选择「容器实例」→「创建实例」
4. 选 GPU 型号：RTX 4090
5. 选镜像：PyTorch 2.5.1 + CUDA 12.4（已有 train_env 基础）
6. 创建后通过 SSH 或 JupyterLab 进入

### 2. 数据和模型上传
```bash
# AutoDL 提供网盘上传
# 大文件（如 Qwen2.5-7B 模型约 14GB）建议用 modelscope 直接下载
# 详见 scripts/02_download_model.py
```

### 3. 长时间训练建议
```bash
# 使用 nohup 后台运行，避免 SSH 断开导致训练中断
nohup bash scripts/03_train_lora.sh > train.log 2>&1 &

# 查看训练日志
tail -f train.log
```

### 4. 关机省费
```bash
# 训练完成后立即关机（数据不会丢失）
# AutoDL 控制台 → 关机
# 下次开机继续使用
# 需要注意的是扩容的付费数据盘无论开机关机，会持续扣费
```
