# 数据集格式说明

## 数据格式

本项目采用标准的 **指令微调（Instruction Tuning）** 格式，适用于 Qwen2.5 等大语言模型。

### 样本结构

每条数据包含 3 个字段：

| 字段 | 作用 | 示例 |
|------|------|------|
| `instruction` | 明确告知模型需要执行的任务类型（固定句式） | `"请提取以下内容中的摘要信息"` |
| `input` | 待处理的原始文本内容 | `"保持身体健康的五个方法：..."` |
| `output` | 符合指令要求的预期结果 | `"多喝水、规律运动、充足睡眠..."` |

### 设计原则

#### instruction（指令）
- 使用**祈使句**明确任务目标
- 采用**固定句式**建立稳定任务映射
- 即使遇到类似表述（如"请总结以下要点"）模型也能正确响应

#### input（输入）
- 每条内容为**动宾短语**（动词+名词）
- 包含细节描述（数字、规格、方法等）
- 平均长度 50-200 字

#### output（输出）
- 从 input 中提炼**核心名词/动宾短语**
- 使用中文顿号分隔（、）
- 无顺序要求（除非原文有优先级）
- 平均长度 3-5 个短语

### 质量控制标准
- 100% 覆盖 input 中的关键条目
- 不添加原文未提及的信息
- 不修改原文的语义

## 文件说明

| 文件 | 说明 |
|------|------|
| `sample_dataset.json` | 示例数据集（10 条），用于快速验证流程 |
| 你的训练集 | 替换为 `train.json`，建议 1000+ 条 |
| 你的验证集 | 替换为 `val.json`，建议 100+ 条 |

## 数据准备流程

```bash
# 1. 准备原始数据（CSV/TXT 任意格式）
# 2. 使用预处理脚本转换为标准格式
python src/preprocess_data.py --input raw.csv --output data/train.json

# 3. 检查数据格式
python src/preprocess_data.py --check data/train.json
```

## 数据来源建议

| 类型 | 推荐数据集 |
|------|----------|
| 中文摘要 | LCSTS（新浪微博新闻摘要） |
| 中文实体 | CN-DBpedia |
| 英文摘要 | CNN/DailyMail、XSum |
| 领域定制 | 企业内部文档脱敏后人工标注 |
